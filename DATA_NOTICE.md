# Data and Attribution

The Markdown snapshots are third-party material collected from public GitHub
repositories. Their original authors retain their rights. Repository names,
paths, and pinned commit links are preserved in the manifests and histories.
Consult the source repositories for applicable licenses. Inclusion here does
not relicense that material.

The CMU Pronouncing Dictionary is distributed with its original notice in
`data/nltk_data/corpora/cmudict/README`.

Annotation JSON files are publication exports of the frozen author assignments
and designated resolved set. The original working files are not modified by
the replication scripts. Model predictions are separated under `rq4/`.

The package contains research data that can include commands or instructions.
Analysis scripts parse those files as text and never execute their contents.
