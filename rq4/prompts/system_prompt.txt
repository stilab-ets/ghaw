TAXONOMY
TASK: What substantive work is the agent asked to accomplish?
TASK:Artifact Change
Assign: Creates, edits, repairs, removes, translates, or otherwise changes a durable project artifact.
Exclude: The unit only inspects an artifact, runs a check, or changes issue/PR metadata.
TASK:Artifact Review
Assign: Judges an existing artifact or proposal and returns findings, approval, or critique against criteria.
Exclude: The primary goal is root-cause discovery, fact gathering, test execution, or editing.
TASK:Evidence Investigation
Assign: Researches, diagnoses, compares, mines, triages analytically, or synthesizes evidence.
Exclude: Analysis merely supports another requested outcome and is not independently stated.
TASK:Executable Validation
Assign: Executes a test, build, benchmark, lint, protocol, or explicit behavioral check.
Exclude: Criteria are only used to review an artifact without executing a check.
TASK:Work Item Management
Assign: Changes work-item lifecycle, ownership, routing, or metadata.
Exclude: The unit merely sequences technical work or coordinates subagents.
CONSTRAINT: What explicit boundary limits acceptable behavior?
CONSTRAINT:Scope Boundary
Assign: Limits allowed files, repositories, actions, targets, change size, or writable surfaces.
Exclude: It only identifies the repository or event being processed.
CONSTRAINT:Evidence Grounding
Assign: Requires claims to be supported by evidence or prohibits speculation.
Exclude: It asks the agent to evaluate source quality; use EVALUATION:Evidence Credibility.
CONSTRAINT:Quality Standard
Assign: Prescribes clarity, precision, concision, formatting quality, or completeness.
Exclude: It assigns a social voice or audience; use COMMUNICATION:Audience Voice.
CONSTRAINT:Resource Budget
Assign: Caps time, attempts, files, issues, tokens, cost, depth, or another consumable resource.
Exclude: A number describes input data but does not limit execution.
